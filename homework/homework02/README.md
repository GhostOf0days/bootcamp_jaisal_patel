# Stage 02 — Tooling Setup (Practice)

This folder practices Stage 02 tooling setup for the Pokemon Set Screener project: a reproducible folder scaffold (`data/`, `src/`, `notebooks/`, etc.), secrets managed through `.env`, a shared `src/config.py` helper, and `notebooks/00_project_setup.ipynb` to verify Python, NumPy, and environment variables end-to-end. The real project code lives in `project/` at the repo root.
